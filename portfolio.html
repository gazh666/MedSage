Core Features

核心功能矩阵

从患者入口到临床运营，覆盖完整诊疗链条。每一环都强调医学合规、证据溯源与安全保障。

💬对话分诊

AI 驱动的聊天与症状分诊工作流，引导式完成第一手患者评估，快速判断紧急程度并分级。

🩺多智能体诊断

分诊 → 症状 → 影像 → RAG → 诊断 → 治疗方案，LangGraph 编排完整诊断流水线与报告生成。

📋诊断报告与方案

自动生成结构化诊断报告、鉴别诊断、用药方案与随访计划，附病危情况应急联动。

📚RAG 医学知识库

检索增强生成的医学知识工作区，接入 PubMed / MedlinePlus / OpenFDA 等权威来源并带引用溯源。

🩻影像 / 胸片分析

胸部 X 光等医学影像智能分析，辅助影像诊断，融入多模态诊断流程。

⚙️临床运营控制台

随访计划、预约排班、数据导出、离线同步等临床运营工具，支撑真实落地场景。

🛡️治理与审计后台

药物安全校验、完整审计追踪、临床医生反馈与偏见监测面板，保障安全合规。

🗂️证据溯源体系

每一次诊断与回答都带完整引用元数据（来源、URL、摘要、相似度、证据等级与校验时间戳）。

Secondary Development

二次开发：肺音诊断深度集成

在既有前后端链路之上，深度打通本地 PBRNet 呼吸音模型，并增强推理结果的可视化呈现，让肺音听诊从「可用」升级为「可解释、可视化」。

1

全链路打通 · 上传到报告

浏览器上传 wav → FastAPI 端点校验（20MB / 仅 wav）→ 16kHz 单声道重采样 → 补齐 8s → kaldi fbank → 归一化 → PBRNet 推理 → 结果写入 LangGraph 诊断节点 → 落库与报告生成。

2

模型进程级单例懒加载

PBRNet（AST 频域编码器 + BEATs 时域编码器 + MMTA 融合 + adapter）权重仅在服务启动后首次请求时加载一次，避免每次请求重复加载大模型。

3

四分类概率输出（新增）

后端 `predict()` 新增返回 normal / crackle / wheeze / both 完整概率分布，替代原先仅 top-1 标签，支撑前端可视化与更可信的诊断呈现。

4

低可信度安全标注

当呼吸音置信度 < 0.7 时，诊断报告强制标注「听诊可信度低」，提示临床医生复核，符合医疗安全规范。

Autonomous Agent

二次开发：自主诊断 Agent（Harness + ReAct Loop）

在既有 LangGraph 固定流水线之上，新增「工具执行环境（Harness）+ ReAct 主循环（Loop）」：让模型自主决定何时、调用哪些工具、调用几次，直到循证信息充分再给出诊断——由「预定流程」升级为「自主推理」。

5可调用工具
2核心组件（Harness + Loop）
8最大推理迭代轮数
100%工具调用轨迹可审计

5 个能力工具

📝

analyze_symptoms

把患者自由文本症状结构化：主诉、持续时间、严重度、诱因等。

🫁

analyze_lung_sound

呼吸音 wav 听诊，输出 normal/crackle/wheeze/both 四分类与置信度。

🩻

analyze_medical_image

解读医学影像（胸片/CT/皮肤病灶/MRI），返回所见、严重度与建议。

📚

retrieve_medical_evidence

本地知识库 + PubMed/MedlinePlus/OpenFDA 循证检索，带来源与排名。

🚑

find_nearby_clinics

根据经纬度检索附近社区医疗设施，用于紧急情况转诊联动。

🧩

ToolRegistry

统一注册与分发上述工具，并一键转换为 StructuredTool 供 bind_tools 使用。

Engineering & Evaluation

二次开发：工程化增强与效果评估

补齐真实 agent 系统最关键的工程底座——可量化效果评估、长期上下文工程，以及国产大模型适配，让「模型 + Prompt + 网页」真正升级为可评测、可上线、可审计的企业级 agent。

100%诊断命中率（12 / 12）
75%分诊一致率（9 / 12）
0.87平均置信度
3+国产 LLM 适配
1

离线效果评估体系（新增）

新增 backend/scripts/eval_agent.py 与 eval_cases.json（12 条专家标注病例），复用线上 DiagnosisAssessment / TriageResponse 标准 schema，量化诊断命中率、分诊一致率与置信度，让效果可度量、可回归。

2

上下文工程（长期记忆 + 历史兜底）

诊断端点自动注入患者档案中的过敏史、慢病史到医学上下文；聊天端点实现服务端历史兜底，从数据库恢复最近会话并做 20 条窗口截断，防止上下文无限增长、避免遗漏长期病史。

3

国产大模型插件化适配（去 Gemini 硬依赖）

LLM 客户端改为 provider 无关，通过环境变量即可切换通义千问 Qwen / DeepSeek / 智谱 GLM 等 OpenAI 兼容接口，无需翻墙即可跑通完整诊断链路。
